# Revised manuscript (v2)

`HNL_Voter_Model_v2.pdf` is the revised edition of the HNL voter model paper.
It is built from `main.tex`; every figure and table is generated from the
committed HNL v2 result files, not typed by hand.

## Build

Requirements: TeX Live with `IEEEtran`, `booktabs`, `amsthm`, and `latexmk`;
Python 3.10+ with the repository's `hnl` package installed or on `PYTHONPATH`.

```bash
make            # figures + tables + PDF
make figures    # regenerate paper/figures from ../results
make tables     # regenerate paper/tables from ../results
make pdf        # compile main.tex (latexmk + bibtex)
make release    # copy main.pdf to HNL_Voter_Model_v2.pdf
```

From the repository root, the result files are produced by:

```bash
python -m hnl.cli reproduce --root .
```

## Files

| file | role |
|---|---|
| `main.tex` | manuscript source (IEEEtran conference, two columns) |
| `refs.bib` | bibliography |
| `figures/*.pdf` | vector figures generated by `make_figures.py` |
| `tables/*.tex` | table fragments generated by `make_tables.py` |
| `HNL_Voter_Model_v2.pdf` | compiled revised edition |

The original manuscript remains at the repository root as
`HNL Voter Model.pdf`; the v1 code is preserved at tag `v1.0-legacy`.

## Notes

- The paper reports a re-analysis, not a new model. Section III fixes the
  specification; Section IV proves the component-wise absorbing-state result;
  Section VI reports the paired experiments.
- All numerical claims in the paper are traceable to `../results/` and the
  manifest in `../results/manifest.json`.
- The paper uses the same dataset as the original report (CC0; see
  `../docs/DATA.md`).
